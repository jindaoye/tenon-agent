# 自动化评测

评测选取 Terminal-Bench 2.0 的 20 道任务与 SWE-bench Pro 的 10 道公开任务，每题独立运行三次，共 90 次。使用原题面、固定源镜像和原评分器，不因作答失败额外重跑。

## 结果

| 指标 | 修复前 | 修复后 |
| --- | ---: | ---: |
| 按全部尝试计算的通过率 | 69/90（76.67%） | **74/90（82.22%）** |
| 第一轮 | 23/30 | 25/30 |
| 第二轮 | 23/30 | 25/30 |
| 第三轮 | 23/30 | 24/30 |
| 三次全部通过的任务 | 20/30 | **24/30** |
| Terminal-Bench 2.0 子集 | 52/60（86.67%） | **57/60（95.00%）** |
| SWE-bench Pro 子集 | 17/30（56.67%） | 17/30（56.67%） |

综合通过率提高 **5.56 个百分点**。本轮 90 次均完成并取得原评分；16 次评分未通过，没有记录到整题超时、接口中断或运行基础设施异常。上轮未通过结果包含 11 次评分失败、5 次超时、3 次接口中断和 2 次基础设施异常，均保留在总体分母中。

结果同时存在退步：ELF 提取题由 3/3 变为 0/3；Ansible `1c06c46…` 由 3/3 变为 2/3。不能将总体改善理解为所有题目都改善。

## 方法与配置

- 模型：`gpt-6.1-sol`，Chat Completions。
- `temperature=0`、`max_tokens=8192`、`context_size=128000`。
- 每题作答上限 900 秒，本轮预留 60 秒用于收尾；环境准备和正式评分另计。
- 未指定采样 seed；三次重复用于观察稳定性，不称为三个固定 seed。
- 每道题使用独立容器工作区，Agent 与评分器分离，保留原评分结果。
- 本批关闭长期记忆、Skills、MCP 和子 Agent，主要覆盖模型、执行运行时及容器工具。
- 本轮完成时间：2026-10-22；评测使用品牌更名前的项目快照。

工程优化涉及完成前检查、重复观察提醒、验证记录归并与模型/工具调用的时限控制。两轮题面 hash 与主要模型参数一致，但存在多处工程变化、模型输出波动和外部接口状况变化，分数差异不能单独归因于某一处修改。
